# Level plans (German)

One file per CEFR level says what that level's German texts must contain together. The keys are the same as Italian's (`content/it/curriculum/README.md`); the grammar sequence is each topic's `level` and `order` in `content/de/grammar/`.

Two things differ from Italian. Registers are `du` and `Sie`, and *Sie* is the third person plural (`3p`), so A1 needs it from the first texts. German writes compounds as one word (*Haustürschlüssel*), which makes a text look harder by rank than it reads; once the German pipeline splits compounds, a compound counts as known when its parts are. Every number is a first guess, to be tuned on the first texts.
